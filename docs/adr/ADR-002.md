# Login and user session in the frontend
 
**Status:** Approved
 
**Context:** We need users to log in, and the frontend needs to know if they are a student or staff.
 
**Decision:** The login page sends login, password and role to the backend `POST /login`. We only keep login, name and role in localStorage so a refresh doesn't log the user out. The password is never saved.
 
**Alternatives:** We could keep the password too and log in again automatically, but it is the user's SDU password and anything in browser storage can be read. We could also keep nothing and log in on every refresh, which is safer but annoying.
 
**Consequences:** The password is never stored, but the saved role can be edited by hand and the backend gives no token, so nothing else checks who is calling. The user stays logged in until logout, and nobody can sign in if the backend is down.
